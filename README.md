# ABOUT
Cachy is a personl AI based memory agent, it can store and retrive your memories and present them to you.

You can ask cachy for anything you had stored in it and it will retrive and deliver it to you and if you say something new then it will store it in the app automatically.

Cachy runs totally offline using the Gemma 4 model which could easily be operated in any low end phone.

Cachy offers a very simple design with just a text box and a send button which is enough for almost all of your queries.
